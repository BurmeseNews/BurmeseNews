နည်းပညာ01

Website တစ်ခုကို ဘယ်လိုစတင်တည်ဆောက်မလဲ

HTML၊ CSS နဲ့ JavaScript တို့ရဲ့ အခြေခံကို လေ့လာပြီး ကိုယ်ပိုင် Website တစ်ခု ဖန်တီးကြည့်ပါ။

ဆောင်းပါး ဖတ်ရန်

HTML က Website ရဲ့ ဖွဲ့စည်းပုံကို ဖန်တီးပေးတယ်။ CSS က အရောင်နဲ့ ဒီဇိုင်းကို ပြင်ဆင်ပေးပြီး JavaScript က Search လို လုပ်ဆောင်ချက်တွေ ထည့်ပေးနိုင်တယ်။ အခြေခံတွေကို လေ့လာပြီး ကိုယ်ပိုင် Project လေးတစ်ခုနဲ့ စမ်းသပ်ပါ။

အင်တာနက်02

အင်တာနက်ကို လုံခြုံစွာ အသုံးပြုနည်း

ကိုယ်ရေးအချက်အလက်နဲ့ Online Account တွေကို ကာကွယ်ဖို့ သိထားသင့်တဲ့ အချက်များ။

ဆောင်းပါး ဖတ်ရန်

Account တစ်ခုစီအတွက် မတူညီတဲ့ ခန့်မှန်းရခက်သော Password ကို သုံးပါ။ Two-factor authentication ရနိုင်ရင် ဖွင့်ထားပါ။ မသိတဲ့ Link တွေကို မနှိပ်ပါနဲ့။ Password နဲ့ အတည်ပြုကုဒ်တွေကို တခြားသူတွေကို မပေးပါနဲ့။

ဗဟုသုတ03

နေ့စဉ် ဗဟုသုတတိုးပွားအောင် လုပ်နည်း

အချိန်နည်းနည်းပေးပြီး နေ့တိုင်းအသစ်တစ်ခု လေ့လာနိုင်ဖို့ လွယ်ကူတဲ့ နည်းလမ်းများ။

ဆောင်းပါး ဖတ်ရန်

နေ့စဉ် မိနစ် ၁၅ မိနစ်ခန့် သတ်မှတ်ပြီး စိတ်ဝင်စားရာ အကြောင်းအရာတစ်ခုကို ဖတ်ပါ။ အရေးကြီးတဲ့အချက်တွေကို မှတ်စုရေးပြီး ယုံကြည်ရတဲ့ ရင်းမြစ်တွေနဲ့ ပြန်လည်စစ်ဆေးပါ။ လေ့လာထားတာကို လက်တွေ့အသုံးချကြည့်ပါ။

ရှာဖွေမှုနဲ့ ကိုက်ညီတဲ့ ဆောင်းပါး မတွေ့ပါ။
